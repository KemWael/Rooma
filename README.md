# 📚 منصة مذاكرة تالتة حاسبات

موقع واحد فيه 6 مواد، ولكل محاضرة: شرح بالعامية المصرية + لاب تفاعلي، وتدريب بالإنجليزي على 4 مستويات (T/F ← Complete ← MCQ ← Essay) بتصحيح تلقائي، وفلاش كارد بتكرار متباعد، وفيديو قصير (أقل من 3 دقايق).

| المادة | الكود | المحاضرات |
|---|---|---|
| Computer Network II | IT301 | 12 |
| Digital Signal Processing | IT303 | 11 |
| Operating Systems | CS301 | 11 |
| Internet Programming | IT304 | 5 |
| Computer Architecture | IT312 | 11 |
| Multimedia | IT302 | 12 |

## ▶️ تفتحه إزاي

**أسهل طريقة:** افتح `index.html` في المتصفح (Chrome أو Edge).

**الأفضل (عشان التقدم يتحفظ بين المواد):** شغّل server صغير من الفولدر الرئيسي:

```bash
python -m http.server 8770
```

وبعدين افتح http://localhost:8770

**أونلاين لأصحابك:** من الـ repo على GitHub ← Settings ← Pages ← Source: `Deploy from a branch` ← اختار `main` و `/ (root)` ← Save. بعد دقيقة هيبقى فيه لينك تبعته لهم.

## 📁 الترتيب

```
index.html                      ← الصفحة الرئيسية (كل المواد)
<المادة>/_مذاكرة/
    00_خريطة_المادة.html        ← خريطة المادة + الفيديوهات + متتبع التقدم
    assets/                     ← الستايل والأنيميشن واللابات
    LecNN_<الاسم>/
        1_شرح.html
        2_حل_وتدريب.html
        3_فلاش_كارد.html
<المادة>/_فيديوهات/lecNN/
    renders/final/*.mp4         ← الفيديو النهائي + الـ Thumbnail
    src/timeline.js             ← سكريبت الفيديو (اللي اتعمل منه)
<المادة>/*.pdf                  ← المصادر الأصلية (المحاضرات والكتب)
```

## 🎬 إعادة بناء فيديو (اختياري)

محتاج Node.js و ffmpeg و Python. من جوه فولدر الفيديو:

```bash
./make.sh "<اسم الفيديو>" NN
```
